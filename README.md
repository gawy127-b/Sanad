# سَنَد — النسخة الأولى القابلة للتشغيل

منصة عربية RTL مبدئية لطلاب تالتة ثانوي وتانية بكالوريا، مبنية انطلاقًا من واجهة سند الأصلية.

## التشغيل محليًا

1. ثبّت Node.js 20 أو أحدث.
2. انسخ `.env.example` إلى `.env` وغيّر `SESSION_SECRET` إلى قيمة عشوائية طويلة.
3. نفّذ:

   ```bash
   npm install
   npm start
   ```

4. افتح `http://localhost:3000`.

قاعدة البيانات SQLite تُنشأ تلقائيًا في `data/sanad.db`، وجلسات الدخول في `data/sessions.db`.

## الموجود في هذه النسخة

- إنشاء حساب وتسجيل دخول وخروج.
- فصل المحتوى حسب المسار الدراسي (تالتة ثانوي / تانية بكالوريا).
- قسم الشرح والمراجعات مع موارد قابلة للإضافة من قاعدة البيانات.
- قسم اختبارات بأسئلة اختيار من متعدد، تصحيح وحفظ النتائج.
- قسم مسابقات ولوحة متصدرين ونقاط مرتبطة بنتائج الاختبارات.
- منظم مذاكرة بمهام محفوظة لكل حساب.
- لوحة مختصرة تعرض المهام والاختبارات والنقاط.
- الاحتفاظ بمقدمة الموقع وهوية الألوان الأصلية.

## ملاحظات إطلاق مهمة

هذه نسخة تأسيسية وليست جاهزة للنشر العام قبل استكمال لوحة الإدارة وإدارة المحتوى، HTTPS، إعداد `SESSION_SECRET` قوي، سياسة الخصوصية، النسخ الاحتياطي، ومراجعة أمنية. لا توجد حسابات إدارية افتراضية. الموارد والأسئلة الموجودة تجريبية لتوضيح سير العمل ويجب استبدالها بمحتوى المنهج المعتمد. يمكن نقل SQLite إلى PostgreSQL عند التوسع.

## هيكل المشروع

- `server.js`: API والمصادقة وقاعدة البيانات.
- `public/index.html`: واجهة سند والوظائف التفاعلية.
- `data/`: ملفات قاعدة البيانات التي تُنشأ عند التشغيل.
